# 引言规划（填好的范例）：最低工资标准上调与企业劳动收入份额

说明：这是 2026-11-08 用 `templates/02_引言规划.md` 填的一份，题目借自杜鹏程等（2022，《世界经济》第 2 期）。它示范的是格子怎么填、每句从哪来；本文事实（F、M）是借那篇论文的结果充当的，真写自己的论文时换成自己的事实清单。范文拆解、文献摘录与正文四版在作者本机的工作目录，未随技能分发。

## A 题目
- X：各地最低工资标准的调整（2004 年《最低工资规定》施行后逐年上调，政策推动的劳动价格外生上涨）
- Y：企业劳动收入份额（劳动报酬总额／增加值）
- 层面：企业（工业企业数据库）
- 结果一句话：最低工资每上涨 10%，企业劳动收入份额下降 0.17 个百分点（F1，借杜鹏程等 2022）
- 识别一句话：各省自定标准、各地调整时间与幅度不同，同一年份不同地区企业面对的劳动价格冲击不同（P2、P3）
- 本文最想卖什么：填空白加换视角（最低工资文献很少落到分配；份额文献把劳动价格当内生结果）

## B 矛盾来源与思路式
- 矛盾来自：目标与现实的距离（国家要提高劳动报酬比重，最低工资是直接工具，份额却在下降）
- 选：第一路第 2 式"目标到制度下沉"
- 为什么：自变量是政策工具，结果变量就是国家目标的企业层面指标；范文里 H41（税收分成差异与资本流动）走的就是"目标 → 文件 → 基础性制度 → 差异 → 回到目标"
- 范文里最接近的一篇：杜鹏程等（2022）第 1 至 3 段走反差型（成就 → 然而 → 事实 → 卡尔多事实 → 缺口 → 一方面另一方面 → 本文），可作第二路备选
- 作者偏好：本例作者偏爱从国家目标过渡

## C 动笔前的一句判断
提高劳动报酬在初次分配中的比重是明确的国家目标，最低工资是政府直接抬高劳动价格的工具，两者本该同向；份额却在最低工资普遍上调的年份下降，原因要到企业的要素替代里找。
