# zh-econ-scaffold：中文经济学论文的脚手架式写作

这是一个给 AI 用的写作流程（Claude Code 里叫"技能"，skill）。它不让 AI 直接"根据这一段生成一段"，而是先向你要材料，再按顶刊的写法一步步搭出引言：定逻辑链、分段落、逐句填、机械核对、独立审稿。

它解决的是三个老问题：AI 写的中文学术段落结构像、语感差；数字、文献、政策表述容易编；写完没人能证明它对不对。

## 它怎么工作

六步，每步有产出，缺材料就停下来要，不替你补：

| 步 | 做什么 | 产出 |
|---|---|---|
| 0 收材料 | 题目、三到五篇同题顶刊全文、本文的事实清单、政策法规原文 | 材料齐不齐的清单 |
| 1 拆范文 | 只拆与目标段落同位置的段，逐句标功能、抽骨架、记哪句挂数字哪句挂政策 | 范文拆解表 |
| 2 立事实 | 把你的结果、机制、制度条文、背景数据编号 | 事实清单 |
| 3 规划 | 题目 → 矛盾从哪来、走哪一式思路 → 动笔前的一句判断 → 段落序列 → 首段句链 | 规划表（前四格先给你确认） |
| 4 落句 | 按句链逐句写，每句只能用事实清单、范文拆解、政策原文里有的东西 | 正文 |
| 5 校 | 脚本查禁用词、句长、衔接词；引号内文字到原文逐字比对；文献逐条定位 | 对照表与自检报告 |
| 6 审 | 另开一个不看过程的会话，只给它正文和事实清单 | 审稿意见与修改记录 |

规则来自对近五年《经济研究》《管理世界》《世界经济》《中国工业经济》等刊物的统计：52 篇引言 2003 句逐句标了 32 类功能，2370 篇全文数了衔接词和用词。

## 安装

**Claude Code 用户**（推荐）：

```bash
git clone https://github.com/qingshanliuci/zh-econ-scaffold.git ~/.claude/skills/zh-econ-scaffold
```

然后新开一个 Claude Code 会话，说"我要写论文引言，第一段怎么规划"就会触发。也可以直接输入 `/zh-econ-scaffold`。

**其他 AI 工具的用户**（Codex、Cursor、网页版 Claude 或 ChatGPT）：`SKILL.md` 本身就是一份完整的流程说明，把它和 `templates/` 里的模板贴给模型即可；`references/` 三份参考按需贴。脚本需要 Python 3，没有第三方依赖。

## 用之前准备什么

1. **题目**：自变量 X、因变量 Y、企业还是地区层面、依托什么政策或冲击。
2. **范文**：三到五篇同 X 同 Y 的近五年顶刊全文，至少同 Y。没有就说，流程会停在规划这一步。
3. **事实清单**：按 `templates/00_事实清单.md` 填，至少填到主结果。引言是从结果倒着写的，没有结果只能写到段落规划。
4. **政策原文**：你要引的文件原文或 gov.cn 链接。引号里的话只能逐字抄原文。

## 请你帮忙测评什么

用你自己正在写或写过的题目跑一遍，然后告诉我们三件事：

1. **规划表前四格对不对**：矛盾来源选得对不对、段落序列像不像你那个小领域的顶刊、动笔前那句判断是不是你想说的。
2. **写出来的段落哪句不像**：指出具体哪一句，为什么不像，顶刊会怎么写。
3. **哪一步卡住了**：材料要得太多、模板看不懂、脚本报错、规则有错，都算。

反馈请开一个 issue，模板里有格子。**事实清单里有你未发表的结果，不要贴进公开 issue**，只贴规划表和写出的段落就够。

## 目录

```
SKILL.md                    流程说明（AI 读的主文件）
templates/                  六份模板：事实清单、范文拆解、引言规划（含贡献点表）、对照表与自检、审稿人提示、摘要句链
references/                 七份规则：思路库（四路十六式）、32 类句子功能与骨架、首段末句怎样把问题立住、
                            每段第一句怎么写、贡献段与创新点怎么写、摘要怎么写、衔接词与用词规则
scripts/find_exemplars.py   在本地论文库里找同题范文
scripts/lint.py             语感检查：禁用词、句长、"然而"次数、句首衔接词占比
scripts/quote_check.py      引号内文字到政策原文或 gov.cn 页面逐字比对
examples/                   一份填好的规划表：最低工资与企业劳动收入份额
```

## 已知局限

- 规则覆盖引言（含每段第一句、首段末句、贡献段）和摘要；文献综述整节、理论机制段、结论与政策建议的专门规则还没做。
- 摘要规则的样本是 2024 至 2026 年五刊 57 篇逐句标注，其中《管理世界》只有 9 篇；全库 3192 篇只做了机械统计。
- 范文检索脚本依赖本地论文全文库，没有的话直接向用户要范文。
- 句子功能库的类目有一次修订（32 类改 34 类），统计数字还是修订前的。
- 文风规则的完整版在作者另一个技能 zh-academic 里，这里只放了衔接词和用词两份；没装那个技能也能用。
