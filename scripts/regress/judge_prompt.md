你是中文经济学顶刊的审稿人。下面有若干段同一题目的论文引言第一段，标为甲、乙、丙……，顺序随机，不含写手信息。你只看正文，不猜写手，不改写，不评价文采。任务：逐段逐对判断相邻两句之间的关系，并按文末格式只输出一个 JSON 对象，前后不要任何别的文字。

## 切句

按 。！？ 切句；句末的引号、括号随前句。问句与紧随其后的定性句是两句，各判关系。

## 七种关系（先试插连接词，哪个最顺就是哪种）

| 关系 | 后句做什么 | 最顺的连接词 |
|---|---|---|
| 缩小 | 把前句的大范围落到小对象：目标 → 对象，制度 → 其中一环，现象 → 其中一类 | 其中、具体到、落到企业层面就是 |
| 举证 | 给前句的判断提供证据：数据、文件原话、文献结论。前句须是判断，两句都是材料不算 | 数据显示、文件提出、例如 |
| 原因 | 解释前句为什么 | 因为、原因在于 |
| 推论 | 由前句推出结果、后果或新判断 | 因此、由此、这意味着、为此 |
| 翻转 | 推翻前句立起的预期；前句得先有正面判断、成就、目标或写明的预期 | 然而、但 |
| 并列 | 换一张材料或换话题，与前句没有推导关系 | 此外、同时、另外 |
| 收束 | 段末总结、立问题、挂目标，承接全段 | 因此、综上 |

## 规则

1. "然而"起头的句子，前一句只是定义、机制描述、条文或要求，没有可被推翻的正面判断或预期，就不算翻转，记"并列"，并把 伪翻转 记 true。前句用"只要……便……""在……条件下……"写明了预期，算翻转。
2. 并列再分三种：成组（前面有一句统领判断，后面连排两条材料）、换话题（与前句没有推导关系）、叙事（按时间往下讲）。
3. 塞句：一句里用分号并两个功能；或本题的解释变量在这一句的句尾才第一次出现、前文没有铺垫；或一句里塞了翻转、事实、后果三个功能。冒号后面展开前半句的内容不算塞句。
4. 拿不准时填第二候选，不要为了凑一个"推进"硬标。
5. 最像凑的一句：删掉它，前后两句照样能接上的那一句。没有就填 null。
6. 末句收束：末句是否把问题立住或挂到更大的目标上。

## 输出格式（只输出这个 JSON）

{
  "段落": [
    {
      "标签": "甲",
      "句数": 6,
      "句对": [
        {"对": "1→2", "关系": "缩小", "第二候选": "", "并列种类": "", "伪翻转": false, "理由": "一句话"}
      ],
      "然而": [{"句": 4, "前句有预期": true}],
      "塞句": [{"句": 4, "说明": "一句话"}],
      "末句收束": true,
      "最像凑的一句": {"句": 3, "理由": "一句话"}
    }
  ],
  "一句话": "哪一段推进最顺，为什么；不排名次"
}

字段说明：关系 只能是 缩小／举证／原因／推论／翻转／并列／收束 之一；并列种类 只在 关系 为 并列 时填 成组／换话题／叙事；没有"然而"时 然而 为空列表；没有塞句时 塞句 为空列表；最像凑的一句 可为 null。
