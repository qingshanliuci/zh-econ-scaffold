# 结论与政策建议规划（模板）

用法：全文定稿、摘要写完之后填。建议只能从本文的发现推出来；写不进下面 A 表的发现不许出现在建议里，A 表里没有对应发现的建议也不许写。写法规则见 `references/policy-recommendations.md`。

## A 发现清单（从正文抽，每条写一句，带表号或节号）

| 编号 | 类型 | 发现（方向、对象、幅度） | 出处（表／节） | 能推出什么政策含义（一句，先不写措施） |
|---|---|---|---|---|
| F1 | 主发现 | | | |
| M1 | 机制 | | | |
| H1 | 异质性 | | | |
| E1 | 进一步发现／副作用／反直觉结果 | | | |
| N1 | 本文算出的数字（阈值、弹性、份额） | | | |

检查：主发现、机制、异质性、进一步发现四类至少各有一条；本文算出的数字若有，必须列出，它是最难被别的论文照搬的材料。

## B 结论回顾（四到九句，占全节三到四成；后面每一点用到的发现都要在这里出现过）

| 句 | 功能 | 落句 |
|---|---|---|
| 1 | 结论回顾-做法（"本文基于 D，考察 X 对 Y 的影响"） | |
| 2 | 结论回顾-发现（"研究发现，……"） | |
| 3 | 结论回顾-机制异质性 | |
| 4 | 结论引申（由发现得出的判断，不含建议动词；可省） | |
| 5 | 建议总起（"基于上述结论，本文提出以下政策启示："） | |

## C 建议点规划（三点为主；每点一行）

| 点 | 论点句（序数起头，35 字左右，动词或主体起头，说要调什么往哪调） | 依据句（回扣 A 表哪一条：F／M／H／E／N 编号；起头"本文研究发现"一类） | 措施句（工具、对象、幅度、时序、谁来做） | 限定或风险（对不同组的差异化安排；要防止什么；可省） | 具体度自评（1 口号／2 方向／3 可操作） |
|---|---|---|---|---|---|
| 1（接主发现 F1，定方向） | | | | | |
| 2（接机制 M1 或异质性 H1，定着力点或差异化） | | | | | |
| 3（接进一步发现 E1 或数字 N1，写纠偏、审慎或参数） | | | | | |

检查：
- 每点都有依据句，且依据句指向 A 表某一条；没有依据的点删掉。
- 建议方向与发现方向一致：发现是负面效应或无效的，建议写审慎、纠偏、别过度，不写"进一步加大"。
- 对效应弱的组要写"加大帮扶"时，先交代为什么弱（机制或异质性的解释），否则不写。
- 本文算出的阈值、弹性、份额，至少用在一点里。
- 每点点名谁来做（中央、地方政府、监管部门、企业、金融机构）；不写"政府应、企业应、个人应"三层并列。
- 论点句不写成判断句（"X 是 Y 的基础"），要有动作；25 到 40 字，序数起头。
- 依据句以"本文研究发现""本文的机制分析表明""本文的模拟显示"起头，点名具体结果；"研究表明"起头的必须是本文结果，他人结果写"已有研究发现"并注文献，未检验的判断写"本文虽未直接检验，但……"。
- 点数两到四点，不凑；一套序数词用到底；按实证顺序排（主效应、机制、异质性、进一步发现），纠偏型或带数字的那一点放显眼位置。
- 本文未检验的对象或议题不写进建议；确需提，放局限或展望。

## D 收尾与局限

- 末句：最后一点的措施句收住，不另加"综上所述"总评。
- 研究局限与展望：按刊决定（中国工业经济四成以上写，其余刊两成左右）；写就两三句，局限要具体到数据或识别，展望指向可做的下一步。

## E 自查

- 建议部分占全节六到七成；结论回顾不超过全节四成。
- "本文"只出现在结论回顾句、总起句和依据句里；措施句不写"本文"。
- 没有"加强监管""完善制度"这类不说调什么的空句；每句说清对象与方向。
- 没有与本文发现相悖的建议；本文最有政策含义的发现（副作用、阈值、反直觉）没有被跳过。
- 用词按 `register-rules.md` 查一遍。
