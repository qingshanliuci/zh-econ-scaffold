# 引言规划（schema）

填法：从上到下，每一格填满才往下走；填不出的格写"待补：要什么"，不猜。所有事实只能来自《事实清单》（F、M、P、D 编号）和《范文拆解》（R 编号）。A 到 D 填完先给作者看，确认后再填 E。

## A 题目
- X（自变量、政策或冲击）：
- Y（因变量）：
- 层面：
- 结果一句话（方向与数量，引 F 编号）：
- 识别一句话（为什么能识别，引第 3 节）：
- 本文最想卖什么（反转命题／第三条路／新尺子／换视角／填空白／翻案）：

## B 矛盾来源与思路式
- 矛盾来自（选一）：目标与现实的距离 ／ 成就与隐患的反差 ／ 理论与前提的冲突 ／ 制度规则与设计预期的落差
- 选哪一路哪一式（`references/intro-thinking.md` 四路十六式）：
- 为什么这一式适合本题（自变量的性质：政策工具、新技术、价格成本、制度规则、待上升为命题的改革）：
- 范文里最接近的一篇及其走法（R 编号，起笔从哪起、几步到变量）：
- 作者偏好（例如偏爱从国家目标过渡）：

## C 动笔前的一句判断
读者读到"本文"之前要相信的那句话（一句，不带"本文"）：

## D 段落序列
| 段 | 这一段让读者接受什么 | 主功能 | 首句功能与怎么接上段 | 末句怎么收 | 用哪些材料（F／M／P／D／R 编号） | 谁在此进场（Y／X／本文） |
|---|---|---|---|---|---|---|
| 1 | | | | | | |
| 2 | | | | | | |
| 3 | | | | | | |
| 4 | | | | | | |
| 5 | | | | | | |
| 6 | | | | | | |

首句一列按 `references/paragraph-openers.md`：写这段首句的功能（文献段多为文献概括，机制段多为制度规则或理论引述，本文段为本文做法，贡献段为贡献总起或第一条）和接法（接上段的对象、接上段立的问题、接上段结论往下推；不用"此外""然而"硬接）。末句一列按 `references/landing-the-question.md`。

检查（逐条写通过或改法）：
- 第一段不出现"本文"：
- 从起笔到本文变量三到七步：
- 每段首句接上段，不以衔接词开头硬接：
- 每段末句有收法，首段末句用定性／研究意义／问题后果／说必要之一，不用"有待检验"：
- 文献只有三种身份（垫脚石、靶子、空白），压进判断句，不排队：
- 贡献段第一点回扣 C：
- 政策引述之后一两句内落到本文对象：

## E 第一段的句链

| 句 | 功能 | 骨架来源（R 篇-段-句 ／ 功能库 类目-编号） | 材料（F／M／P／D／文献） | 落句 |

检查：
- "然而，"一段一次：
- 翻转、事实、后果分三句，不塞一句：
- 末句先给分量再给内容，办法与思路相配（反差型问句加定性、制度型双重定性、理论型说后果、目标型挂目标），分量词从 `landing-the-question.md` 第二节挑：
- 每句比上一句往前走一步，没有原地重复：
- 行内词对照《范文拆解》第 3 节词表：

## F 第二段以后
每段一张 E 表。文献段按链"文献概括→文献点名→文献评价→文献缺口"，制度段按"制度规则→机制推演"，理论段按"理论引述→前提条件或文献分歧→机制推演"，本文段按"本文做法→本文发现→机制与异质性发现"，贡献段按"贡献总起→（论点句→文献句→本文收尾句）×N"，三点为主，近年多一点一段。

### F1 贡献点规划（写贡献段前先填，规则见 `references/contributions.md`）
| 点 | 贡献类型（视角或问题／对象或情境／数据／方法与识别／机制／理论／测度／政策含义） | 论点句（本文做了什么，一句短的） | 文献句（已有研究做到哪、缺什么，出处放这句） | 本文收尾句（怎样不同、多做了什么，用的动词） |
|---|---|---|---|---|
| 1（回扣 C 的那句判断） | | | | |
| 2 | | | | |
| 3 | | | | |

检查：点数两到四点，三点最常见；第一点回扣 C，视角类常放第一点，政策含义类放最后；每点与引言前文的文献段分工（前文说文献做了什么，这里说本文多做了什么）；动词从"为……提供、拓展、丰富、补充、揭示、识别"里选；不与摘要、结论逐句重复；没有"填补空白""理论意义""据我们所知"。

### F2 摘要
全文定稿后按 `templates/05_摘要句链.md` 单独填，不在这里写。
