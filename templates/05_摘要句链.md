# 摘要句链（模板）

用法：全文定稿后再写摘要。材料只从事实清单（F 主结果、M 机制与异质性、P 制度）和正文里取，摘要不能出现正文没有的结论。写法规则见 `references/abstract.md`。

## A 刊与字数

- 投哪一刊：___
- 字数目标（顶刊四分位，下四分位至上四分位，按 3192 篇摘要算）：世界经济 260 至 310 字；经济研究 330 至 430 字；中国工业经济 410 至 490 字；数量经济技术经济研究 375 至 480 字；管理世界约 375 至 435 字（只有 14 篇，参考）；没定刊按 300 至 450 字。
- 句数 4 至 7 句，均句长 70 字上下。

## B 句链

默认六句，按顶刊最常见的序列；机制、异质性、进一步发现三句按本文有什么保留一到三句，没有就删，不凑。

| 句 | 功能 | 材料编号 | 落句 |
|---|---|---|---|
| 1 | 背景或问题缺口（讲世界，不出现"本文"） | P／D | |
| 2 | 做法（数据、识别、模型；"本文基于／利用／以 P 为准自然实验"） | 事实清单第 2、3 节 | |
| 3 | 主发现（"研究发现，X ……Y"，带方向，必要时带数字） | F1 | |
| 4 | 机制（"机制分析表明……""通过……渠道"） | M | |
| 5 | 异质性或进一步发现（"……在……企业中更为明显""进一步研究发现……"） | M | |
| 6 | 收尾一句：贡献或意义为主（"本文为……提供了……"），后半句可带一个政策对象（"也为……提供了参考"）；或政策启示为主 | | |

## C 检查

- 首句不含"本文"（57 篇顶刊摘要里 50 篇如此）；"本文"第一次出现在第 2 句的做法句。
- 没有单独成句的稳健性（57 篇里只 1 句）；要提，最多作从句附在主发现后，如"该结论在一系列稳健性检验后依然成立"。
- 收尾一句，不分两句各写一种（分两句的只有 3 篇）；贡献句后半带一个政策对象是最常见的收法（27 篇贡献收尾里 21 篇这样写）。
- 允许的合句只有这几种：做法＋问题缺口、主发现＋做法、主发现＋机制、主发现＋异质性、贡献＋政策启示。其余一句一功能。
- 发现句的方向与数字和正文、表格一致；机制与异质性只写正文检验过的。
- 没有"第一、第二"分点，没有"填补空白"，没有"具有重要意义"开头的空句。
- 字数落在所投刊的四分位区间内。
