# 文献综述节规划（模板）

用法：引言的段落序列（`02_引言规划.md` 的 D 表）定了、决定单列一节"文献综述"之后填。先决定要不要单列：顶刊 3178 篇里只有 36% 单列（2024 年后 29%），引言里已经把文献压进判断句、立住了缺口的，不必再单列；单列的刊以《世界经济》《中国工业经济》为多。规则见 `references/literature-review.md`。所有文献只能来自《范文包》和作者给的文献摘录，发现方向要能在原文里定位。

## A 文献清单（先填，每条一行；没读过原文的不许进表）

| 编号 | 作者（年） | 讨论什么（X 的决定因素／Y 的测度／X→Y／机制／方法） | 发现方向一句话 | 对本文的身份（垫脚石／靶子／空白／地图） | 归哪一支 | 出处放法（括注／叙述） |
|---|---|---|---|---|---|---|
| R1 | | | | | | |
| R2 | | | | | | |
| R3 | | | | | | |

检查：
- 每条都能在原文里找到发现方向；只在别人综述里见过的不写。
- 身份至少两种：全是垫脚石的综述立不起本文；至少一条靶子（本文要修正或补的前提、口径、方法）或一处空白。
- 叙述式（"A（年）发现___"作主语）只给要单独讨论的那一两篇：开创性研究、本文直接接着做的、本文要反驳的。其余压进括号。

## B 架构（这一节分几支、按什么分）

- 按什么分支（选一）：按 X 的文献与 Y 的文献分 ／ 按 X→Y 的正反结论分 ／ 按层面（宏观、企业、个人）分 ／ 按方法或测度分 ／ 按理论分支分 ／ 不分支一气写（短节）：
- 几支（两支最常见，三支其次，四支以上少见）：
- 每支一句话：这支文献共同说明什么（这是该段首句要下的判断，不是"这支文献研究了什么"）：
  - 第一支：
  - 第二支：
  - 第三支：
- 分支首句用同一序数格式：总起说"三类"，三支首句就都是"第一类……第二类……第三类"，不混用"首先……另一支……最后"（顶刊分支标记：括号序数 35.5%、首先／其次 26.4%、第 N 21.0%）：
- 要不要总起句（"与本文相关的文献主要有两支：一是___，二是___"，顶刊 16.5% 的节有；分三支以上或两支之间关系不显时写）：
- 节的第一句（按 `references/first-sentences.md` 第二节：直接概括 36.5%、对象定性 23.0%、总起分支 17.4%；不以作者起句、不在第一句写缺口）：
- 与引言分工：引言里已经说过的文献判断不再重复展开；贡献条目放引言，这一节末段只写"本文与上述文献的关系"（顶刊单列文献节的论文，贡献写在引言的占 65%，写在文献节的 11%）：

## C 每段规划（一段一支或一段一个判断；每段四到八句、三百字上下）

| 段 | 段的功能（总起段／分支段／评述段／定位段） | 这段要让读者接受的判断（一句，作者自己的话） | 用哪些文献作证（R 编号，先群后单） | 首句怎么起、怎么接上段（接上段名词／接总起分支／接上段缺口；不用"此外""然而"硬接） | 末句怎么收（归纳这支／立一个小缺口／落到本文） | 这段的靶子或空白是什么 |
|---|---|---|---|---|---|---|
| 1 | | | | | | |
| 2 | | | | | | |
| 3 | | | | | | |
| 4 | | | | | | |

检查：
- 每段先有判断再有文献：段首句是作者对这支文献的概括判断（"已有研究主要从___和___两方面考察___"），不是"A（年）发现___"。
- 文献作证：出处压进判断句句末括号，一句里几条出处用分号隔开；连续三句都以作者名起句就是排队，合成一句判断加括号。
- 每段末句收住：归纳这支说明什么、或立一个小缺口、或落到本文；不以带出处的点名句结尾。
- 缺口不只在最后一段：每支收尾处可以立一个小缺口，末段再合成本文要补的那一个。
- 一段一支，支内按"共识→分歧或局限→缺口"推进，不按作者、不按年代排队。
- 一支的骨架（顶刊组织分最高的篇都这么写）：判断句（作者自己的话，无出处或挂群引）→ 概括句（出处进括号，一括两三条）→ 点名句（一两句叙述式，报出发现，不只说"研究了"）→ 分歧或翻转（有则写，给分歧的原因）→ 收束句（总的来看，这支做到了什么、还差什么）。一段装两支时，收束句可以落在段中。方法类综述：方法→优点→缺点→文献例证→收住→本文选法。
- 缺口要落到对象、变量口径、样本或机制之一，后面跟一句"为什么少"（数据缺失）或"相近文献为什么不算"（A 不等于 B）；只写"鲜有""尚未"不跟原因的缺口弱。

## D 定位段（最后一段，三到五句）

先选落法（顶刊 60 篇末句：贡献 16、定位 13、做法 11、缺口接本文 2，七成落到本文）：
- 缺口句直接接本文（"鉴于鲜有研究从___考察___，本文___"，一两句，短节用）；
- 贡献条目（每条先一句"现有文献___较少／忽视___"再接"本文___"，缺口与本文成对，条目数对应分支数；引言已有贡献段的不再列，顶刊贡献在引言 65%、在文献节 11%）；
- 交代做法（"基于此，本文结合___与___，考察___"，不写贡献词）。
也可以不另写定位段：每支末尾各落一句本文定位（"区别于既有文献，本文___"），三支收法一致。选了这一种，D 表只填末支那一句。

| 句 | 功能 | 落句 |
|---|---|---|
| 1 | 归纳：上述文献共同做到了什么（"综上，已有研究___"，一节至多一次"综上"） | |
| 2 | 缺口：还缺什么（合并前面各支的小缺口成一条，与本文问题对上） | |
| 3 | 定位：本文与上述文献的关系（"与上述研究相比，本文___"／"本文沿着 A 的思路，但___"） | |
| 4 | 做法预告（可省）：本文将用什么数据与识别回答这一缺口；不写贡献条目 | |

检查：
- 缺口句与本文问题一字一句对得上：缺口说"鲜有研究考察企业层面的___"，本文就得是企业层面的___。
- 定位句点名本文接着谁做、与谁不同，不写"填补空白""具有重要理论和现实意义"。
- 贡献条目（第一、第二……）不在这里写，它在引言的贡献段。

## F 自查（写完跑 `python3 scripts/lit_check.py 稿.md`，再对照下面逐条写通过或改法）

- 引用：每千字 4 到 9 条；叙述式不超过三成；连续以作者名起句不超过两句；点名句都报出了发现。
- 节内"本文"：主要在后三分之一；首段只能是"与本文相关的文献"一类总起；末段有"本文"。
- 缺口：至少一句，不超过四句；第一个缺口不晚于节的三分之二处；每处缺口后面跟原因或排除。
- 节末一句落到本文（定位、做法或贡献），不停在评价或机制上。
- 衔接词：句首衔接词不超过两成；"综上（所述）"至多一次；"此外"不超过两次。
- 总起说几支，分支标记就有几处，词对得上（"两支……一支……另一支"；"三类……第一类……第二类……第三类"）。
- 没有"学界普遍认为""众所周知""填补空白""具有重要理论和现实意义""进入视野""日益受到关注"。
- 每一处（作者，年）都能在范文包或文献摘录里定位，发现方向一致；`scripts/quote_check.py` 查引号内文字。
- 与引言不重复：引言里用过的文献判断，这里只在分支里展开，不再原句重说。
